## 🪞 About the Project

This project represents my first fully designed and styled **personal portfolio website**, built from scratch using **pure HTML and CSS** (without frameworks or templates).  
The goal is to practice clean structure, responsive design, and consistent visual identity while introducing myself and my achievements.

---

## 🎯 Objectives

- Apply **HTML structure and semantics**
- Implement **CSS styling and layout techniques**
- Organize multiple pages into one cohesive website
- Learn about **external stylesheets**, **selectors**, and **responsive design**
- Build a visually unified and user-friendly interface

---

## ✨ Features
Modern and minimal layout  
Fully responsive design for mobile & desktop  
Profile images on homepage  
Organized sections: education, gallery, schedule, questionnaire, contact  
Clean typography and color palette  
External stylesheet for maintainability  
Easy to update and expand

## 📁 Project Structure
My-website/
│
├── index.html #  Home page – Introduction and profile section
├── contact.html #  Contact page – Includes contact information or form
├── education.html #  Education page – Academic background and courses
├── gallery.html #  Gallery page – Displays images and visuals
├── schedule.html #  Schedule page – Daily or academic timetable
├── questionnaire.html #  Questionnaire page – Form or survey-like section
│
├── style.css #  Unified external stylesheet for the whole website
│
├── /images #  Folder containing all images used on the website
│ ├── profile1.jpg
│ ├── profile2.jpg
│ ├── gallery1.jpg
│
├── /fonts # (optional) Custom font files if used
│
└── README.md # Project documentation file (this file)

### 📂 Description of Main Files and Folders

| File / Folder | Description |
|----------------|-------------|
| **index.html** | Homepage introducing who I am, featuring my photo and short intro text. |
| **education.html** | Lists educational background and academic achievements. |
| **gallery.html** | Displays selected images or projects visually. |
| **schedule.html** | Contains a sample or personal schedule for structure and design practice. |
| **questionnaire.html** | Includes a simple HTML form for collecting user input. |
| **contact.html** | Provides contact info or a basic form to reach me. |
| **style.css** | The main stylesheet that controls colors, layout, typography, and responsive design. |
| **images/** | Directory for all photos, icons, and graphics used across the pages. |
| **README.md** | Markdown documentation file (this one) describing the website project. |
